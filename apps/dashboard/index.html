Anansi

Self-healing control plane for Bright Data collectors

A scraper does not fail loudly. It returns rows that are shaped right and empty inside, and everything downstream keeps running on nothing. Anansi scores every run against a contract, writes the repair prompt from that contract, and refuses any fix that does not measurably hold — all against the same Collector ID, so nothing downstream is ever repointed.
